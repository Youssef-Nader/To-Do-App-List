# Task Manager App

A responsive React application for managing daily tasks on desktop, tablet, and mobile devices. Tasks are saved in the browser, so they remain available after the page is refreshed.

## Features

- Add, edit, and delete tasks
- Mark a task complete with the check icon
- Click the green check icon again to mark a task incomplete
- Filter tasks by All, Completed, or Incomplete
- Persist tasks with browser local storage
- Responsive layout for phones, tablets, and desktop screens
- Smooth task, completion, filter, and dialog animations with reduced-motion support

## Built With

- React
- React Router
- Context API
- Material UI icons
- CSS media queries

## Run Locally

Install the dependencies and start the development server:

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

- `npm start` starts the development server.
- `npm test` runs the test suite.
- `npm run build` creates a production build.
